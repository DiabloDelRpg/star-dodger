# ⭐ Star Dodger

Un esquivador de meteoritos hecho con JavaScript puro y Canvas. Los efectos de sonido se generan por código con la Web Audio API (sin archivos de audio).

**Jugar:** https://diablodelrpg.github.io/star-dodger/

## Cómo se juega
- Muévete con **← →** o **A / D** (en móvil, desliza el dedo).
- Esquiva los meteoritos rojos y atrapa las estrellas (+10 puntos).
- Tienes 3 vidas; la dificultad sube con el puntaje.
- El récord se guarda en tu navegador (`localStorage`).

## Archivos
- `index.html`: página y canvas
- `style.css`: estilos
- `game.js`: lógica, audio con osciladores, bucle `update()`/`draw()`, colisiones y dificultad
